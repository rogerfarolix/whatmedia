# Politique de sécurité

## Versions prises en charge
Seule la dernière version mineure publiée reçoit des correctifs de sécurité.

## Signaler une vulnérabilité
**N'ouvre pas d'issue publique.** Utilise l'onglet *Security → Report a vulnerability* du dépôt GitHub (GitHub Security Advisories), ou écris à `<EMAIL_SECURITE>`.

Indique : description, étapes de reproduction, impact, version concernée.

Délais visés : accusé de réception sous 72 h, évaluation sous 7 jours, correctif selon la gravité. Tu seras crédité dans l'avis de sécurité si tu le souhaites.

## Périmètre
- Application web (`/app`) et landing
- Serveur de secours (`/api/v1`)
- Images Docker publiées et paquet npm `@whatmedia/core`
